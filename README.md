# Overthinker Bot 🫧

Overthinker Bot is a web-based AI companion designed to help you process your worries and overthinking. It features two unique modes to cater to your emotional needs: Comfort Mode (🌸) for reassurance and Harsh Truth Mode (🐉) for rational, direct feedback.

## Features

*   **Interactive Chat Interface:** A soothing, responsive UI to spill your worries.
*   **Dual Modes:** Toggle seamlessly between "Comfort" and "Harsh Truth" modes to get the type of response you need right now.
*   **Streak Tracking:** Encourages daily reflection by tracking your usage streak.
*   **Overthinking Profile Analysis:** Generates an AI-driven profile analyzing the patterns in your worries over time.
*   **Local Data Storage:** Your chats, streaks, and settings are saved securely on your local device using `localStorage`.

## Setup Instructions

1.  **Clone or Download:** Get the codebase to your local machine.
2.  **Open `index.html`:** Simply open the `index.html` file in any modern web browser. No server setup is required to run the basic UI!
3.  **API Key Setup:**
    *   To use the AI features, you will need a free Google Gemini API key.
    *   When you first open the app, a modal will appear guiding you to [Google AI Studio](https://aistudio.google.com/app/apikey) to generate a key.
    *   Paste the key into the app. It is saved locally in your browser and never sent anywhere else.

## Technologies Used

*   **HTML5** for structure
*   **CSS3** for styling, animations, and responsive design (Vanilla CSS)
*   **JavaScript (ES6+)** for DOM manipulation, local storage, API integration, and app logic
*   **Google Gemini API** for generating AI responses

## Usage

*   Type your worry into the input box and hit **Send**.
*   Use the toggle at the top to switch between **Comfort 🌸** and **Harsh Truth 🐉** modes before or during your chat.
*   Click **✨ Analyze Me** to see a customized profile based on your recent worries.

Enjoy a more mindful approach to overthinking!
